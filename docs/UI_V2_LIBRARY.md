# Библиотека v2 — 14 октября 2026

Сначала завершена страница поиска: персональная история, категории и отмена устаревших результатов. Затем библиотека переработана по пользовательскому концепту. Используются существующие темы и выбранный фон; новые фоновые изображения и зависимости не добавлены. Сборка EXE в эту работу не входит.

## Оформление и действия

- Верхние карточки избранного и офлайн-треков с текущими счётчиками.
- Обзор коллекции, карточки плейлистов и таблица недавно добавленной музыки из `get_library()`.
- Отдельная панель создания, импорта, конвертации и поиска по плейлистам. Полный список прокручивается независимо от содержимого.
- Шапка выбранного плейлиста с обложкой, названием, доступным количеством треков и сохранённой датой обновления. Воспроизведение, перемешивание, экспорт в M3U8 и удаление через существующее подтверждение.
- Таблица сохраняет прежние действия с треком. Дата добавления берётся из доступных метаданных, для неизвестной длительности показывается прочерк.
- Пустая коллекция предлагает найти музыку. Ошибка загрузки позволяет повторить запрос; запоздалый ответ другого плейлиста не заменяет текущую коллекцию.
- На узком окне выбор плейлиста становится выпадающим списком, второстепенные столбцы скрываются. При отсутствии размытия остаются непрозрачные поверхности. Состояния фокуса и reduced motion сохранены.

## Пользовательские обложки

Через карандаш или меню можно выбрать PNG, JPEG или WebP размером до 2 МБ и сбросить выбор. Обложка сохраняется в localStorage как предпочтение оформления v2; она не записывается в музыкальную базу и не переносится с экспортом плейлиста. Без пользовательской обложки используется коллаж реальных треков либо локальная заглушка. На главной выбранная обложка применяется при обновлении карточек.
