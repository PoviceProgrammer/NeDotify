# Windows: статусы замечаний аудита

Реестр охватывает **454 AUD-замечания** и 15 межмодульных сценариев.
Статусы взяты из отчётов владельцев; детали, доказательства и ограничения
сохранены по ссылкам. Наличие строки не означает ручную проверку GUI или
безусловное закрытие замечания. Итог — в [сводке](WINDOWS_REMEDIATION_STATUS.md).
