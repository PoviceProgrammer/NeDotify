# Windows audit remediation — application and bridge

Scope: `main.py`, `core/api.py`, bridge/UI server/DNS/OAuth helpers,
application lifecycle, tray, plugins, and their integration contracts.
The original `FULL_PROJECT_AUDIT.md` is preserved. No application window,
installed executable, browser or GUI was launched during this continuation.
Tests use temporary profiles; the user's library was not cleared.

“Fixed” below describes source and automated contracts. It does not assert
manual WebView playback, native window transitions, frozen-runtime loading,
or live-provider acceptance.
