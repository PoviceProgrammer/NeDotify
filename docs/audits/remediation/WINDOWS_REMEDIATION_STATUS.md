# Windows: итог исправлений аудита — 2026-10-22

Область: Windows desktop, Python/pywebview и `ui/web_new_v2/`, включая
оформление macOS. Исходный документ —
[FULL_PROJECT_AUDIT.md](../FULL_PROJECT_AUDIT.md). Android в эту работу не входит.

Приложение, собранный EXE и GUI во время продолжения не запускались по условию
пользователя. Проверки используют временные профили, SQLite, заглушки провайдеров
и изолированные Node DOM harnesses. Пользовательская библиотека не очищалась.

## Что исправлено

- Запуск и завершение: готовность bridge, последовательная доставка событий,
  защита от взаимных блокировок, отмена фоновых задач, сохранение перед выходом,
  обработка частично созданного приложения и ограниченное ожидание работников.
- Воспроизведение: согласованные очередь/индекс, отмена устаревших результатов,
  отдельная полоса исполнения разрешения трека, восстановление сессии и точный
  учёт прослушивания при паузах и смене скорости.
- Библиотека: транзакционный импорт, безопасное объединение дубликатов,
  миграции старых схем, постраничная выдача и общее количество треков,
  атомарная запись тегов и обложек, согласованное удаление истории.
- Сеть и загрузки: общая проверка адресов, ограничения ресурсов прокси,
  корректные Range/HLS/CORS, блокировка удалённых запросов в offline,
  отмена/повторы загрузок, проверка целостности и один владелец файлового кеша.
- Настройки и приватность: подтверждение сохранения на диск, откат при ошибке,
  маскирование секретов, отсутствие ключей в localStorage и URL изображений,
  явное согласие на Last.fm независимо от наличия ключей.
- UI: обработка ошибок и повторов, устаревших ответов и переходов мини-плеера,
  реальные кнопки импорта/очистки/согласия, кириллица в локальных шрифтах,
  исправление CSS-конфликтов, отложенная загрузка стилей и ограничение blur.
- Инструменты и упаковка: строгие проверки состава исходников, непустых
  эталонов и результатов бенчмарков; зависимости с хешами, корректные каталоги
  PyInstaller, проверяемые нативные зависимости и механизм подписи релиза.

Для каждого из **454 AUD-замечаний и 15 межмодульных сценариев** указаны статус,
доказательства и ограничения в [реестре](WINDOWS_FINDINGS_STATUS.md).
AUD-127 на текущем исходнике не воспроизводится: 40 комбинаций очереди
подтверждают сохранение текущего трека при ограничении сессии в 200 записей.

## Итоговая проверка

Итоговый прогон и статические проверки записываются после завершения последней
группы регрессионных тестов. Результаты ранних контрольных запусков сохранены
в тематических отчётах и не подменяют итоговый результат.

## Что остаётся проверить вне этого прохода

| Область | Статус |
|---|---|
| AUD-461, AUD-471: новые pixel goldens и измерения производительности | Требуют запуска приложения; не выполнялись по условию пользователя. Старые результаты не выдаются за свежие. |
| AUD-463 и другие сценарии бенчмарков | Инструменты отвергают пустой/неуспешный сценарий. Прокрутка, FPS и реальное воспроизведение в WebView не измерены. |
| Нативные окна, tray, Snap/DPI, системные диалоги, звук, OAuth и живые провайдеры | Исходники и контракты проверены автоматически; ручная проверка и сетевые smoke tests не выполнялись. |
| AUD-498: нативные файлы для release | Внешний проверенный комплект отсутствует. Release-сборка намеренно останавливается без него. |
| AUD-499: доверенная подпись | Механизм реализован; реальная подпись требует сертификата и закрытого ключа владельца. Сборка и подписание не выполнялись. |
| Строгий `check_source_manifest.py --require-tracked` | Выявляет новые файлы рабочего дерева, ещё не добавленные в Git. Чужие и новые изменения не индексировались и не коммитились. Обычная проверка состава проверяет наличие всех исходников. |
| AUD-191: неподдерживаемый HLS URI | Сохранён отказ для не-HTTP(S) URI, включая локальные AES-ключи. Это документированное отклонение от предложения аудита пропускать атрибут, защищённое регрессионным тестом. |

Наличие записи в реестре не означает, что все 454 замечания безусловно закрыты
или что готовый установщик проверен в реальной Windows-сессии.
