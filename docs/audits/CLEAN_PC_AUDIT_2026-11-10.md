# Проверка Windows на чистом профиле — 10.11.2026

## Объём и границы

Проверен Windows-проект. Android/Linux не изменялись. VPN Happ оставался включённым.
Это проверка кода, комплекта поставки и изолированных запусков на текущей Windows,
а не запуск на отдельной свежей виртуальной машине. Наличие установленного WebView2,
системных драйверов и кодеков на хосте не скрывается этим тестом.

## Исправление

Установщик не ограничивал ОС и архитектуру: позволял установить AMD64-сборку с
Python 3.14 на неподходящую систему. Добавлены `MinVersion=10.0` и
`ArchitecturesAllowed=x64os`. ARM64 в эту проверенную поставку не входит.
Основание: [поддержка Windows в Python](https://docs.python.org/3/using/windows.html),
[архитектуры Inno Setup](https://jrsoftware.org/ishelp/topic_archidentifiers.htm).
Проверка: `tests/test_clean_pc_installer.py`; компиляция Inno Setup завершилась успешно.

## Что требует чистой VM

Установить на Windows10/11 x64 без WebView2; проверить установку runtime с нуля,
перезагрузку и автозапуск, физический звук/смену устройства, tray/горячие клавиши,
обновление поверх старой версии и удаление. Не отключать VPN пользователя для этих проверок.
Старые ОС и 32-битная Windows установщиком отклоняются. Нет гарантии доступности
всех внешних каталогов, приватных треков или одинаковой работы антивирусов/драйверов.

## Дополнительная диагностика нативного декодирования

Первый расширенный диагностический прогон завершился DecodeError в вызове
`miniaudio.decode_file` для MP3 по пути с кириллицей. Это ошибка выбранного
диагностического способа: приложение использует потоковое чтение `stream_file`.
Отдельная реальная проба с одинаковым MP3 показала: get_file_info и stream_file
успешны для ASCII и кириллицы; decode_file успешен только для ASCII.
Диагностика переведена на потоковое чтение, как в продукте, без изменения продукта.
`tests/test_lufs_unicode_path.py` дополнительно проверяет реальный анализ WAV
по пути с кириллицей (пройден). Ошибка первого прогона сохранена в
`.test_runs/packaged-audit-error.json`; это не засчитывается как успешный прогон.

## Финальная проверка frozen-runtime

`tools/bench/results/youtube-download-audit-20261110-084957-3b320a.json`:
продуктовые модули загружены из PyiFrozenLoader, профиль временный, PATH только
Windows/System32, cookie не используются. До подготовки ready=false; после
настоящей сетевой установки и проверки FFmpeg/ffprobe ready=true, оба managed.
AppApi → DownloadManager → YouTubeService → преобразование MP3 завершены:
8 533 512 байт, 213,072 секунды, queue=completed, is_downloaded=true,
download_complete=1, download_failed=0. Потоковый native-декодер прочитал
10 226 069 кадров при 48 кГц. Диагностический процесс завершился с кодом0;
временные инструменты, медиа и EXE удалены вместе со своими временными каталогами.
Этот тест не заменяет прослушивание через HTML5 Audio в обычном окне приложения.

Дополнительный обычный EXE запуск с выключенным для дочернего процесса поиском
локальной закреплённой версии WebView2 прошёл через системный runtime:
видимое окно, bridge, первый запуск, 4,15 с. Лог

Две новые проверки (ограничение ОС/архитектуры и реальный Unicode WAV) прошли.

## Что увидит новый пользователь

1. Установщик проверит Windows10+ x64 и WebView2; если runtime отсутствует,
   скачает его у Microsoft. Сбой не выдаётся за успешную установку.
2. Первый запуск создаст собственную библиотеку и покажет подготовку компонентов.
   Кнопка «Подготовить автоматически» загрузит недостающий FFmpeg с проверкой
   контрольной суммы. Для этой стадии нужен интернет; Python вручную не требуется.
3. Можно выбрать папку и формат скачивания, затем пройти настройку оформления
   и артистов или пропустить её. Пустая библиотека допустима.
4. Поиск и воспроизведение используют включённые источники; скачивания сохраняются
   в выбранной папке и отмечаются в библиотеке. Персональные рекомендации требуют
   выбранных артистов и развиваются по истории/лайкам.
5. Zapret по умолчанию выключен. При первом включении идёт подбор стратегий;
   для запуска драйвера Windows может запросить повышение прав.

Ограничение внешнего YouTube: Node/Deno в поставку не входят. Реальная проверка
выше прошла без них, но yt-dlp предупреждает, что некоторые форматы без JS-runtime
могут отсутствовать. Это не подтверждение доступности любого видео.
