## Поведение первого запуска

На чистом профиле enabled=false, auto_start=false, autoupdate=false. Первое открытие приложения не запускает Zapret и не включает автоматическую загрузку обновлений.

При ручном включении отсутствующие файлы скачиваются из закреплённого релиза GitHub, проверяется SHA-256 и состав архива. Для установленного приложения текущий код выбирает подкаталог zapret в подтверждённой реестром папке установки. При необходимости запрашиваются права администратора. Успешная отправка UAC сама по себе не считается успешным запуском: требуется подтверждение процесса.

При повторном открытии автоматический запуск происходит после загрузки окна и только при enabled=true и auto_start=true. Отмена UAC, сбой загрузки, падение процесса, остановка, гонки запуска/остановки и обновления покрыты автоматическими тестами с подменой системных вызовов.

## Что не подтверждено

Реальный запуск WinDivert через UAC, остановка повышенного процесса и воспроизведение через Zapret при выключенном VPN в этой проверке не выполнялись. Работоспособность установленного старого EXE и опубликованного установщика не установлена. Для полного подтверждения требуется установка сборки с текущими исправлениями и отдельная проверка обхода на реальной сети без VPN. Успешные тесты исходников не заменяют эту проверку.
