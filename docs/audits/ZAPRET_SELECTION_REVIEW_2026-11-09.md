# Проверка подбора стратегий Zapret

Проверены исходники Windows перед сборкой установщика 9 ноября 2026.

## Исправления

- Отмена через интерфейс передаётся потоку подбора. Второй вызов переключателя не запускает параллельную остановку и не перезаписывает выбранный режим.
- Обычный запуск из другого потока отклоняется во время подбора. Отмена проверяется под блокировкой перед запуском следующей попытки.
- Ошибка HTTPS-проверки или исключение после создания процесса приводит к попытке остановки принадлежащего подбору процесса. Если остановка отклонена, пользователю возвращается ошибка, а фактическое состояние остаётся видимым.
- Завершение/остановка приложения отменяет подбор. Устаревшая проверка не может принять остановленный процесс за рабочую стратегию.
- Признак завершённого подбора сохраняется после настроек выбранной стратегии и только при живом процессе.
- Уведомление о переподключении имеет кнопку закрытия и не появляется повторно в той же серии попыток после закрытия.

## Границы проверки

Подбор перебирает пять встроенных пресетов, начиная с выбранного пользователем. Проверяются два HTTPS-адреса YouTube через requests без прокси из переменных окружения. Проверка не использует пользовательские cookies. Ошибочные HTTP-ответы, редиректы и сетевые исключения не считаются успехом.

Это проверка HTTPS-доступности YouTube, а не загрузки медиапотока googlevideo.com. Рабочий HTTPS-пресет может не подходить для конкретного CDN, сети или провайдера. Реальный обход с выключенным VPN не подтверждён автоматическими тестами. При смене процессов Windows может запрашивать UAC повторно.

Регрессионные сценарии находятся в tests/test_zapret_selection.py и tests/test_zapret_ui_e1.py; используются изолированные профили и подменённые системные/сетевые вызовы. Личная библиотека пользователя не изменяется.
