# Очередь Windows

Изучены `src/renderer/app.js::renderQueueView`, `removeTrackFromQueue`,
`queueHistory` и зависимости `package.json` Riff на коммите
`860b3276b74b3904ec6d3dcbdf3e12209022c18b`.
Источник: https://github.com/rootscripts/riff/blob/860b3276b74b3904ec6d3dcbdf3e12209022c18b/src/renderer/app.js

Адаптированы принципы общих строк треков, запуска из очереди, удаления,
перестановки с сохранением текущей позиции и отдельной истории переходов.
Electron-зависимости не добавлены. Реализация использует очередь Python
NeDotify и существующие проверки entry_id/revision. Уведомление об авторстве
Riff: Copyright (c) 2026 rootscripts, MIT; текст в `licenses/riff-MIT.txt`.

Кнопка находится непосредственно после «Настройки звука» в нижнем баре.
Раздел «Далее» содержит текущую запись и будущие треки; «Прослушано» —
реальные переходы в обратной хронологии. История не вычисляется из номера
выбранной строки. Кнопка отражает открытое состояние, Escape и нажатие
за пределами панели закрывают её без блокировки интерфейса.

Проверены логика группировки в `tests/test_queue.py`, существующие тесты
очереди и UI. Chromium: открытие, разделы, скрытые действия истории,
закрытие и aria-expanded работают в обычном и macOS-стиле Windows.
Нативное приложение не запускалось.
