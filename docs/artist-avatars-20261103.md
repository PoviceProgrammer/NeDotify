# Фотографии исполнителей в Windows — 2026-11-03

Исправлен раздел «Топ исполнителей»: фото располагается поверх буквенной
заглушки; после успешной загрузки заглушка удаляется. Изменение общее для
обычного и macOS-стиля Windows. Версия кеша повышена, чтобы исключить старые
результаты поиска.

Фото поступают из подтверждённых каталогов, профилей владельцев записей
SoundCloud и YouTube. Запись проверяется по названию и владельцу. Совместные
кредиты поддерживаются; посторонний первый результат Deezer не принимается.
Для неоднозначных имён используются композиции из истории. Пачки независимы,
каждый исполнитель получает свой срок поиска, готовые фото отправляются сразу.

Проверка реального Python-моста: `tools/bench/audit_artist_avatars.py`.
Скрипт читает пользовательскую БД через SQLite read-only, копирует в память,
вызывает штатный `AppApi.get_artists_avatars` и проверяет декодирование фото.
Фактический топ: HOME, The Weeknd, BG Muz, VØJ/Narvent, Daft Punk ft. Pharrell
Williams, Gorillaz, HELLBLADE, @svrreal, PHARAOH, Cube Rubik. Найдены и
декодированы все 10 фото.

`tests/home_artist_avatars_browser.cjs` проверил эти результаты в Chromium с
CSS обоих стилей: 10 фото в каждом, без буквенных заглушек, с совпадающими
границами карточки и изображения. 81 целевая проверка Python/JS прошла.
Нативное окно NeDotify не запускалось. Доступность фотографий новых исполнителей
по-прежнему зависит от источника и возможности подтвердить профиль.
