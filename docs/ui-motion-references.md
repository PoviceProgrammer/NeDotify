# Референсы анимаций Soneth для Windows

Проверено 15 ноября 2026 года. Официальные материалы музыкальных приложений показывают сценарии взаимодействия. Длительности и кривые для Soneth подобраны под Windows-интерфейс.

| Раскрытие мини-плеера и возврат в основное окно | Сохранить метаданные видимыми и мягко показать управление при наведении. Размеры окна меняются в WinForms, прозрачность блока управления меняется в CSS. | Пересчёт компоновки WebView2 ограничен изменением размера нативного окна. У анимации управления нет фонового цикла. | [Apple Music MiniPlayer](https://support.apple.com/en-jo/guide/music/mus71d7dcfce/mac), [Spotify Desktop Miniplayer](https://newsroom.spotify.com/2024-04-11/spotify-premium-tips-tricks/) |
| Главная, поиск, библиотека, профиль и артист | Проявлять обновлённый блок через opacity и небольшой translate. У виртуальной библиотеки эффект относится к смене данных, прокрутка остаётся прямой. | Одна короткая анимация на блок. Стоимость рендера списка зависит от количества видимых элементов. | [Spotify Desktop и устойчивые области интерфейса](https://newsroom.spotify.com/2023-06-20/spotify-desktop-experience-redesign-your-library-now-playing-views-customize/), [Apple HIG о частых взаимодействиях](https://developer.apple.com/design/human-interface-guidelines/motion) |

В покое нет нагрузки от этих эффектов. | [Chrome о свойствах композитинга и входе/выходе](https://developer.chrome.com/docs/modern-web-guidance/guides/ui-behaviors/motion) |

Оценки нагрузки качественные. Для Windows подходят нативные CSS и Web Animations API. Microsoft рекомендует CSS-анимации для WebView2 и советует избегать частых пересчётов раскладки. При reduced motion состояние отображается сразу. [Рекомендации WebView2](https://learn.microsoft.com/microsoft-edge/webview2/concepts/performance), [Apple Reduced Motion](https://developer.apple.com/help/app-store-connect/manage-app-accessibility/reduced-motion-evaluation-criteria)

## Проверка перед изменением интерфейса

1. Изучите актуальный сценарий музыкального приложения, начиная со Spotify, Apple Music или YouTube Music. Выберите короткую реакцию, помогающую понять результат действия.
2. Адаптируйте принцип под Soneth. Для плавных переходов используйте нативные средства WebView2 и WinForms. Ограничивайте эффект областью изменения и учитывайте плавность, время отклика, заряд батареи и системное уменьшение движения.
3. Для заимствованного ресурса проверьте лицензию файла, атрибуцию и совместимость с Windows. Функциональная польза определяет необходимость свечения, частиц и других затратных эффектов.
4. Запишите источник, способ реализации и ожидаемую нагрузку в [таблицу анимаций](ui-motion.md). Проверьте повторные действия и момент завершения эффекта.

## Источники для дальнейшей работы и лицензии

- **Mobbin и Page Flows** помогают разбирать последовательность реальных экранов. **Dribbble** помогает искать концепты музыкальных плееров. Записи и скриншоты подходят как визуальные референсы. На момент проверки Page Flows вернул HTTP 403 для автоматического просмотра. [Mobbin](https://mobbin.com/), [Page Flows](https://pageflows.com/), [Dribbble Music Player Animation](https://dribbble.com/search/music-player-animation)
- **Motion.dev, Codrops, Uiverse, Animista и Easings.net** подходят для изучения смещений при смене раскладки и кривых. Ядро Motion и элементы из репозитория Uiverse Galaxy распространяются по MIT. Сгенерированный CSS Animista распространяется по FreeBSD с сохранением уведомления при распространении. В Soneth используются собственные ключевые кадры и нативные API. [Лицензия Motion](https://github.com/motiondivision/motion/blob/main/LICENSE.md), [Uiverse Galaxy](https://github.com/uiverse-io/galaxy), [Лицензия Animista](https://animista.net/), [Easings.net](https://easings.net/)
- **Rive** использовался в интерактивной истории Spotify Wrapped 2025. Среда исполнения Rive распространяется по MIT. Права на файл проверяются по карточке конкретной работы, где может быть указана CC BY. [Кейс Spotify Wrapped](https://www.rive.app/blog/spotify-used-rive-for-spotify-wrapped-2025), [Rive runtimes](https://rive.app/use-cases), [Карточка Rive с CC BY](https://rive.app/marketplace/25749-48126-scripting-converter/)
- **LottieFiles и Lordicon** подходят как визуальные ориентиры для короткой обратной связи. Lottie Simple License для бесплатных публичных файлов требует сохранить условия лицензии при распространении файлов и производных. Бесплатные иконки Lordicon требуют указания авторства. Переходы Soneth используют встроенные средства WebView2. [Lottie Simple License](https://lottiefiles.com/page/license), [Лицензии Lordicon](https://lordicon.com/licenses), [Атрибуция Lordicon](https://lordicon.com/docs/license/attribution)
