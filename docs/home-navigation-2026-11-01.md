# Главная, профиль, уведомления и переходы — 1 ноября 2026

Восстановлен отсутствовавший в HTML блок «Для тебя» и request-tagged запрос get_home_mixes. Ошибки и тайм-ауты используют существующую кнопку повтора. Смена текущего трека не запускает генерацию заново.

Адаптирован planMixes из renderer/app.js Riff (commit 44145b575d2ee498929c2b1ec69cfbd64cf3b239): ранжирование артистов по предпочтениям, веса с дневным seed, распределение по максимум пяти корзинам из нескольких артистов. Используются существующие сигналы истории, любимых/плейлистов и кандидаты RecommendationService; существующая фильтрация источников, дублей и исключений сохранена. Количество карточек зависит от реальных данных. Нет принудительного создания плейлистов в библиотеке: карточка открывает состав, кнопка запускает очередь, отдельное сохранение создаёт пользовательский плейлист через существующий мост. Обложки собраны в коллаж.

Кнопкам data-macos-page добавлена навигация: раньше macOS скрывал обычную кнопку профиля, но её замена не имела обработчика. Переходы используют View Transitions для выходящего и входящего содержимого, без движения транспорта/боковой панели; для старого WebView есть WAAPI fallback, reduced motion отключает анимацию. Быстрая навигация пропускает предыдущий переход и не порождает unhandled rejection.

Убраны вторые короткие уведомления из audio_error и download_failed: остаётся единый operation_error. Общий renderer показывает единственную карточку и очередь. Проверка браузером подтверждает, что после закрытия нет второго сообщения от того же события.
