# Поиск v2 — 14 октября 2026

Страница поиска обновлена по пользовательскому концепту: заголовок «Найди свою музыку», пояснение, широкая строка с кнопкой запуска, категории, профиль, сообщения приложения и «Уже прослушано Вами». Фон выбирается в прежнем разделе настроек. Сборка EXE в эту работу не входит.

Карточки используют `get_home_data().history`: последние доступные прослушивания, уникальные исполнители без изменения порядка. Когда имя исполнителя неизвестно, показывается сам трек с подписью «Трек». Данные обновляются при открытии поиска и после начала воспроизведения. Ответы существующего сервиса фотографий заменяют обложки треков; без ответа или при ошибке картинки сохраняется локальный резервный вариант.

«Показать все» открывает исполнителей и треки из доступного ответа истории. Текущий API возвращает десять записей, поэтому этот экран не является полной выгрузкой всей истории пользователя. Названия исполнителей берутся из сохранённых метаданных, в том числе из полей загрузившего трек пользователя на площадке; они не подменяются предполагаемым исполнителем из названия песни.

При вводе запроса история скрывается, при очистке возвращается. Очистка отменяет отложенный запрос и отрисовку списка; ответы старого запроса игнорируются. Запросы профиля исполнителя инвалидируются при смене поискового контекста. Сигнатуры и события Python API сохранены.

«Жанры» открывают шесть направлений, выбор запускает обычный поиск треков. Это подборка поисковых запросов, поскольку отдельного API жанрового каталога нет. Переключение площадки сохранено.

Проверено: 72 теста JavaScript/CSS, существующего поиска и каталога, независимости UI и правил построения истории; 5 сценариев Playwright с четырьмя размерами окна (600×640, 900×700, 1100×800, 1600×1000), очисткой, устаревшими результатами, повтором после ошибки, жанрами, клавиатурой, карточками истории и светлой темой. Дополнительно страница осмотрена в настоящем pywebview с реальными пользовательскими данными.

Скриншоты находятся в `docs/screenshots/ui-v2-search-20261014/`: `native-search.png` — реальное окно; остальные — демонстрационные данные тестового моста. Эти проверки не подтверждают доступность всех внешних музыкальных провайдеров.

Новых зависимостей и удалённых скриптов, стилей, шрифтов или фоновых картинок не добавлено. Резервный ZIP оригинальной v2 сохранён.
