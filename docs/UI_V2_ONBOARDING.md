# Первоначальная настройка NeDotify — 15 октября 2026

Мастер первого запуска переработан на четыре шага: оформление и производительность, звук, медиатека, итог настроек. На широком окне слева показан предпросмотр плеера с пластинкой, справа — текущий шаг. На узком окне остаётся одна колонка с прокручиваемым содержимым и постоянно доступными кнопками перехода. Оформление мастера меняется при выборе темы, не изменяя приложение до сохранения.

Доступны четыре начальные темы: тёмная, полночь, мята и светлая. Режим по умолчанию — баланс; также доступны экономия и все эффекты. Режимы сохраняют согласованные FPS, качество размытия, свечение и состояние частиц. Остальные темы и подробные параметры остаются в обычных настройках.

Шаг звука использует существующий список аудиовыходов Web Audio. Показывает устройства, обновляет список и объясняет ограничения выбора в текущем WebView. Запрос разрешения возможен только по отдельной кнопке. Плавные переходы и нормализация громкости остаются выключенными до выбора пользователя.

Для медиатеки явно выбирается пустая коллекция или импорт плейлиста. Проверяется ссылка YouTube, Spotify либо Яндекс Музыки. Импорт начинается после успешного сохранения и закрытия мастера; его сбой не возвращает первоначальную настройку. Итоговый экран показывает выбранные параметры и позволяет включить автозапуск либо изменить поведение закрытия окна.

Кнопки «Настроить позже» и закрытия передают пустой набор параметров: текущие настройки сохраняются без принудительного включения эффектов. Изменения черновика переживают перезагрузку страницы. Повторные вызовы инициализации не добавляют обработчики. Фокус удерживается внутри диалога; шаги, переключатели и карточки доступны с клавиатуры.

`AppApi.complete_onboarding` проверяет входные значения, сохраняет параметры в реальные категории и подтверждает запись на диск до установки флагов завершения. Ошибка сохранения или автозапуска оставляет мастер доступным для исправления и повторной попытки. В ответе возвращаются фактические настройки, которые сразу применяются к интерфейсу. Старыe флаги `aura_onboarding_done`, `general.first_launch_done` и `personalization.onboarding_completed` сохранены. Мастер ожидает настройки Python, включая позднее подключение моста, чтобы не появляться у уже настроенного профиля.

Изменения: `ui/web_new_v2/js/onboarding.js`, `css/components/onboarding.css`, разметка `index.html`, ожидание настроек в `js/main.js`, метод завершения в `core/api.py`. Новые регрессии находятся в `tests/test_onboarding.py` и `tests/test_onboarding_ui.py`.

Проверки интерфейса: `.test_runs/ui-v2/onboarding.spec.ts`, конфигурация `onboarding.config.mjs`. Проверяются размеры 600×640, 900×700, 1100×800 и 1600×1000, все шаги, светлый предпросмотр, завершение, повторный запуск, ошибки и повтор сохранения, пропуск, импорт после закрытия, сохранение черновика, клавиатура, поздний ответ настроек и выбор аудиовыхода. Снимки с тестовыми данными находятся в `.test_runs/ui-v2/onboarding-shots/`.

UI проверяется на изолированном демонстрационном мосте. Эти проверки не подтверждают работу внешних музыкальных сервисов или воспроизведение через реальное оборудование. Профиль пользователя не сбрасывался, EXE не пересобирался.
