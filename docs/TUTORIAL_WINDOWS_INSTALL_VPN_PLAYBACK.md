# NeDotify на Windows: установка, VPN и первый трек

Инструкция для Windows 10/11. Здесь используется готовый установщик с GitHub Releases: клонировать репозиторий, устанавливать Python или собирать EXE не нужно.

## 1. Скачать установщик NeDotify

1. Откройте [GitHub Releases проекта NeDotify](https://github.com/PoviceProgrammer/NeDotify/releases).
2. Откройте самый свежий релиз (верхний в списке) и разверните **Assets**.
3. Скачайте файл **`NeDotify_Setup.exe`**. Не скачивайте `Source code (zip)` или `Source code (tar.gz)` — это исходники, а не установщик.
4. Откройте скачанный файл и пройдите шаги мастера установки. Можно оставить предложенную папку и ярлыки.
5. Запустите **NeDotify** из меню «Пуск» или с рабочего стола.

Установщик ставит приложение в профиль текущего пользователя. Если Windows показывает предупреждение, сначала проверьте, что файл называется `NeDotify_Setup.exe` и скачан со страницы Releases проекта. Не отключайте защиту Windows ради запуска неизвестного файла.

## 2. Подключить VPN в Happ

Если музыкальные источники не открываются в вашей сети, подключите VPN **до поиска и запуска онлайн-трека**.

1. Откройте [TequilaVPN в Telegram](https://t.me/TequilaVPNbot?start=refugkQUieF) — это реферальная ссылка автора. VPN предоставляется отдельно от NeDotify.
2. Следуйте подсказкам бота, чтобы оформить доступ и добавить выданную подписку/сервер в клиент **Happ**. Не публикуйте ссылку подписки: она может давать доступ к вашему VPN.
3. В Happ откройте экран **«Серверы»** и выберите выданный сервер (на примере на скриншоте это **Tequila ID=225**; у вас имя или ID могут отличаться).
4. В меню режима справа сверху выберите **`TUN - Sing-box`**. На втором скриншоте это пункт **Sing-box** в разделе **TUN**.
5. Нажмите круглую кнопку подключения и дождитесь статуса **«ПОДКЛЮЧЕН»**.

Порядок в меню по скриншоту: **TUN → Sing-box**. Это именно режим VPN-клиента Happ, а не переключатель внутри NeDotify. Если Happ попросит разрешить создание VPN-подключения Windows, подтвердите запрос для самого Happ.

## 3. Найти и проиграть музыку

1. Оставив VPN подключённым, откройте NeDotify. Если приложение уже было открыто, перезапустите поиск или перезапустите приложение после подключения.
2. На главной откройте поиск и введите название песни и исполнителя.
3. При необходимости выберите источник **YouTube Music** или **SoundCloud** в переключателе источника поиска. Онлайн-воспроизведение зависит от доступности конкретного трека у источника.
4. Нажмите найденный трек. Он начнёт воспроизводиться, а очередь появится в плеере.
5. Чтобы проверить звук, убедитесь, что громкость NeDotify и Windows не выключена и выбран нужный аудиовыход.

Можно также запустить подборку на главной, например **«Для тебя»** или **«Моя волна»**: нажмите на нужный трек в подборке, чтобы начать воспроизведение с него.

## Если трек не играет

- Проверьте, что в Happ по-прежнему показано **«ПОДКЛЮЧЕН»**, а активный режим — **`TUN - Sing-box`**.
- Проверьте, что открываются другие сайты, и попробуйте поиск ещё раз. Некоторые треки могут быть недоступны у выбранного музыкального источника.
- Попробуйте другой источник поиска или другую версию трека.
- Если VPN подключён, но сетевые источники всё равно недоступны, переподключитесь к серверу в Happ и заново откройте NeDotify.
- Для локального файла VPN не требуется: добавьте папку с музыкой в библиотеку NeDotify и запустите трек оттуда.
