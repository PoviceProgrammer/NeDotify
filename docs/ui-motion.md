# Анимации окон и разделов Windows

Оба оформления используют `ui-motion.js` и `ui-motion.css`.

- Диалоги и фон: вход 220 мс, выход 170–220 мс, прозрачность и небольшой
  сдвиг с масштабированием. Используются нативные discrete display/overlay
  transitions: JavaScript не задерживает закрытие модального состояния.
- Разделы настроек, аудио, артиста и очереди: scoped View Transitions,
  исчезновение вверх и появление снизу. Последнее быстрое переключение
  отменяет устаревший переход. Имена снимков очищаются после завершения.
- Контекстные меню: выход 150 мс; сразу становятся inert и перестают
  перехватывать указатель, затем удаляются. Есть ограниченный таймер очистки.
- Выпадающие списки: плавные opacity/transform и discrete display transitions.
- Окно настроек: вход и выход карточки и фона без задержки блокировки страницы.

При reduced motion переключение выполняется сразу. В отсутствие View
Transitions остаётся рабочее переключение разделов без ожидания анимации.

`tests/ui_motion_browser.cjs` проверяет реальный Chromium в обоих стилях:
закрытие освобождает клики, повторное открытие остаётся открытым, при быстрых
переключениях побеждает последний запрос, меню удаляются, reduced motion
не задерживает обновление. Нативное окно NeDotify не запускается.
