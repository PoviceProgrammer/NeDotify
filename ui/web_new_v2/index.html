Last.fm

Если включить интеграцию и запросить рекомендации, NeDotify может отправлять Last.fm название и исполнителя недавних треков. Указанное имя пользователя также передаётся Last.fm для запроса его топа исполнителей. Отключение прекращает эти запросы; имя пользователя и API-ключ остаются сохранёнными.

Разрешить запросы к Last.fm
Это отдельное согласие на передачу данных, описанную выше.
Имя пользователя Last.fm
Используется для загрузки ваших топ-исполнителей.
API-ключ Last.fm
Вставьте свой ключ. Сохранённое значение скрыто и не записывается в localStorage.
Какие данные уходят на Last.fm
Last.fm получает имя пользователя, название трека, исполнителя и альбом из вашей истории недавних треков, а также отметки «любимое». Локальная библиотека, пароли и ключи API не передаются.
